# Pablo 사용 안내

Pablo의 기능·사용법을 요청할 때만 제공하는 설명이다. 설치 직후나 매 대화 시작 때 자동으로 실행하지 않는다. 사용자의 언어로 답하며, 전체 안내는 아래 예시를 기준으로 하고 특정 기능 질문에는 관련 부분만 설명한다.

## 답변 기준

짧은 소개 → 작업별 요청 예시 → 디자인 진행 방식 → 자유로운 요청 안내 순으로 구성한다. 기존 대화에서 제공된 자료나 목적을 다시 설문하지 않는다. 작업 범위·납품 기준은 `pablo-workflows.md`, 탐색·고도화 조건은 `pablo-design-dialogue.md`가 기준이다. 변경 시 아래 예시도 그 기준과 대조한다.

안내만으로 파일 생성·수정, 시안 제작, 환경 점검·설치, 외부 호출을 시작하지 않는다. 필요한 지침 읽기는 허용한다. 진행 중인 기준안·버전·피드백·질문·승인 범위를 그대로 보존하고 `design-state.md`를 안내 단계로 덮어쓰지 않는다. 다음 요청은 보존된 작업 맥락과 최신 사용자 지시로 해석한다. 안내 후 “진행해줘”의 대상이 불분명하면 필요한 대상만 확인한다.

디자인·목업과 운영 서비스·백엔드 개발을 구분한다. 파일 형식, 편집 가능성, 내보내기·배포는 실제 도구와 환경에 따라 달라진다. 기능 설명을 위해 환경을 검사하거나 지원 여부를 확인한 것처럼 말하지 않는다.

## 전체 안내 예시

Pablo는 자료와 아이디어를 발표자료·화면·다이어그램 같은 시각적인 결과물로 만드는 디자인 도구예요. 아래처럼 요청해보세요.

| 할 수 있는 작업 | 이렇게 요청하세요 |
|---|---|
| 발표자료·IR Deck 제작 | “Pablo로 이 사업계획서를 10장짜리 IR Deck으로 만들어줘.” |
| UI 목업·랜딩페이지 디자인 | “Pablo로 우리 서비스를 소개하는 랜딩페이지 만들어줘.” |
| 시스템·정보 시각화 | “Pablo로 이 시스템 아키텍처를 시각화해줘.” |
| 기존 PPT 리뷰·수정 | “Pablo가 이 PPT의 가독성과 디자인을 검토하고 수정해줘.” |
| 회사 브랜드 적용 | “Pablo로 이 자료를 우리 회사 브랜드에 맞춰 다시 디자인해줘.” |

새 디자인의 방향이 막연하다면 서로 다른 시각적 시안 3개를 먼저 보여드리고, 선택한 시안에 추가 의견을 반영해 다듬습니다. 명확한 템플릿이나 기존 결과물의 부분 수정은 요청한 범위로 바로 진행합니다.

지원되는 파일 형식과 내보내기는 실행 환경에 따라 달라질 수 있어요. UI·랜딩페이지 디자인과 실제 서비스 운영에 필요한 백엔드 구축은 별도 작업입니다.

만들고 싶은 결과물이나 가지고 있는 자료를 편하게 알려주세요.
